Política de Privacidade

1. Quem somos

A Comu (“nós”, “nosso”) é uma agência especializada em TikTok Shop, registrada no Brasil, com sede em São Paulo. Atuamos em duas frentes:

  • Agência TAP (TikTok Affiliate Platform): gestão de campanhas de marketing de afiliados para marcas
  • MCN (Multi-Channel Network): rede de criadores de conteúdo cadastrados na plataforma TikTok Shop

Contato: dpo@nossacomu.com.br

2. Quais dados coletamos e por quê

2.1 Dados de criadores de conteúdo (MCN)

Coletamos via APIs do TikTok Shop Open Platform:

  • Nome de usuário (username) do TikTok
  • Métricas de performance: GMV (valor de vendas gerado), número de vídeos publicados, visualizações, pedidos
  • Status do contrato MCN (ativo/inativo)
  • Dados de lives realizadas (duração, visualizações, GMV gerado)

Finalidade: gestão interna da nossa rede de criadores, acompanhamento de performance e identificação de oportunidades de campanhas.

2.2 Dados de marcas e campanhas

  • Identificadores de lojas (Shop ID) e nomes de marcas parceiras
  • GMV gerado por campanha e por período
  • Produtos vendidos por criadores em campanhas

Finalidade: relatórios de performance para as marcas que contratam nossos serviços TAP e gestão das campanhas ativas.

2.3 Dados de navegação no sistema interno

  • Logs de acesso ao COMU OS (nosso sistema interno de gestão)
  • Ações realizadas por colaboradores no sistema

Finalidade: segurança e auditoria interna.

3. Como usamos os dados

Os dados coletados via API do TikTok Shop são usados exclusivamente para:

  • Gestão interna das campanhas e criadores
  • Geração de relatórios de performance para marcas parceiras que contrataram nossos serviços
  • Identificação de criadores com potencial para campanhas específicas
  • Monitoramento de resultados e metas contratuais

Não utilizamos os dados para:

  • Venda ou comercialização de informações a terceiros
  • Publicidade direcionada
  • Tomada de decisões automatizadas com efeitos jurídicos sobre os criadores

4. Com quem compartilhamos os dados

  • Relatórios de performance das campanhas contratadas — Execução de contrato; gestão operacional das campanhas e criadores — Legítimo interesse
  • TikTok Shop (origem dos dados) — não compartilhamos dados de volta, apenas consumimos

Não compartilhamos dados pessoais de criadores com nenhum terceiro além dos listados acima sem consentimento explícito.

5. Por quanto tempo guardamos os dados

  • Dados de performance de campanhas ativas: durante toda a vigência do contrato com a marca + 5 anos após o encerramento (para fins contábeis e fiscais)
  • Dados de criadores MCN: enquanto o contrato MCN estiver ativo + 5 anos após o encerramento (para fins contábeis e fiscais)
  • Logs de sistema: 60 meses
  • Ao encerrar a relação com o TikTok Shop Open Platform: todos os dados coletados via API serão excluídos em até 30 dias.

6. Seus direitos (LGPD — Lei 13.709/2018)

Se você é um criador de conteúdo cadastrado em nossa rede ou teve dados tratados pela Comu, você tem direito a:

  • Confirmação e acesso: saber se tratamos seus dados e acessá-los
  • Correção: solicitar a correção de dados incompletos ou desatualizados
  • Eliminação: solicitar a exclusão dos seus dados, respeitados os prazos legais de retenção
  • Portabilidade: receber seus dados em formato estruturado
  • Revogação do consentimento: quando aplicável
  • Oposição: opor-se ao tratamento em determinadas situações

Para exercer qualquer direito, envie e-mail para dpo@nossacomu.com.br com o assunto “LGPD — [Seu Direito]”. Respondemos em até 30 dias úteis.

7. Segurança dos dados

Adotamos as seguintes medidas de segurança:

  • Acesso restrito por função (apenas colaboradores com necessidade específica acessam os dados)
  • Autenticação de dois fatores (MFA) em todos os sistemas
  • Transmissão de dados via HTTPS/TLS (criptografia em trânsito)
  • Armazenamento em infraestrutura com criptografia em repouso
  • Credenciais de API armazenadas em ambiente seguro, nunca expostas em código-fonte

Em caso de incidente de segurança que afete dados pessoais, notificaremos os titulares e a ANPD (Autoridade Nacional de Proteção de Dados) no prazo de 72 horas.

8. Uso de APIs do TikTok Shop

A Comu é parceira oficial do TikTok Shop e acessa dados via TikTok Shop Open Platform API sob autorização expressa da plataforma. O uso dos dados segue:

  • Os Termos de Serviço do TikTok Shop Open Platform
  • As políticas de privacidade do TikTok
  • Esta Política de Privacidade
  • A LGPD (Lei 13.709/2018)

Os dados acessados via API são tratados como dados de terceiros e utilizados exclusivamente para os fins autorizados pelo TikTok Shop.

9. Cookies e rastreamento

O COMU OS é um sistema interno sem acesso público. Não utilizamos cookies de rastreamento, pixels de anúncios ou ferramentas de analytics de terceiros no sistema interno.

10. Alterações nesta política

Podemos atualizar esta política periodicamente. A data da última atualização está sempre indicada no topo do documento. Alterações significativas serão comunicadas por e-mail aos criadores e parceiros afetados com pelo menos 30 dias de antecedência.

  • E-mail: dpo@nossacomu.com.br
  • Site: nossacomu.com.br

Para dúvidas, solicitações ou reclamações relacionadas ao tratamento de dados pessoais, entre em contato pelo e-mail acima. Respondemos em até 15 dias úteis.
